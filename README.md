the chain that boots [[cyber]]: run every component of planetary [[superintelligence]] on a live network, learn from it, then hand the lessons to the protocol.

the idea arrived in 2016 as cyberChain — a decentralized [[cybergraph]]. the Euler network put pagerank inside consensus on GPUs in 2018. [[bootloader/bostrom|bostrom]] launched November 5, 2021: fifty validators, one GPU each, converging on [[focus]] every block.

results by the end of 2024: 3.1 million [[particles]], 2.9 million [[cyberlinks]], 70,000 [[neurons]] — the first live proof that a network computes what matters without any external oracle, and the calibration data behind the [[collective focus theorem]]. where the theory predicted bottlenecks, the bottlenecks appeared.

the bootloader did its job. the current codebase — [[bootloader/go-cyber|go-cyber]], the Cosmos-SDK node behind these chains — is sunsetting in favor of [[soft3]]: the same machine, rebuilt as one provable stack. [[bootloader/bostrom|bostrom]] and [[bootloader/space-pussy|space-pussy]] keep running as chaosnets while soft3 matures.
